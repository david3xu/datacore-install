# v0.1.90 — Helper download resilience and early failure reporting

**Type:** Distribution release carrying bundle **0.1.90**.

## Versioning

- Installer v0.1.90 ships bundle 0.1.90, a version-only bundle.

## Fixed

### Installer

- A failed download of a helper the release carries (worker.sh and the others) now stops the install at the download step, naming the file and saying the download failed. Before, it warned "not installed" and failed later with a misleading "re-run the installer" (e18ee4a).
- The helpers the installer itself runs (worker.sh, install-desktop-entry.py) are always required (e18ee4a, 2b0f59f).
- Downloads retry more patiently (5 attempts, 3 s apart, plus retry-all-errors where curl supports it), which rides out short GitHub release-download outages (e18ee4a).
- Helpers an older release does not carry are skipped without a download attempt (e18ee4a).

## Known limits

- Workers share the bridge's Runtime credential (documented).

## Upgrading

Run `datacore update`:

```sh
datacore update
```
