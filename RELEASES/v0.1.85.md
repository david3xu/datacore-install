# v0.1.85 — Muse workers can run Spark in contributor mode

**Type:** Distribution release carrying bundle **0.1.81**.

## Added

- **A sixth Muse model in the worker catalogue: `muse-spark-1.3-contributor`.** The Muse
  Code CLI resolves that id (`muse model-profile show muse-spark-1.3-contributor`), but the
  bundle catalogue did not list it, so `datacore worker add` refused it and no dispatched
  worker could run Muse Spark in contributor mode. The catalogue and its test now carry
  the alias (bundle `5c37331`, cut as 0.1.81), so after upgrading:

  ```bash
  datacore worker add muse-review@muse-spark-1.3-contributor
  datacore worker add muse-worker@muse-spark-1.3-contributor
  ```

  Each replaces that family's previous model selection and survives prune and upgrades,
  like any exact model selection.

## Notes

- Contributor mode is the same Muse Spark 1.3 at contributor pricing, in exchange for
  prompt content being usable for product improvement. Running a worker in contributor
  mode is now the operator's recorded model choice.
- Nothing else changes: the CLI helpers are unchanged from v0.1.84, and the bundle is
  otherwise 0.1.80 with the catalogue alias added.
