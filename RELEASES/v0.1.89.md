# v0.1.89 — Preflight report, project map sync, and worker change visibility

**Type:** Distribution release carrying bundle **0.1.89**.

## Versioning

- Installer v0.1.89 ships bundle 0.1.89.

## Fixed

### Installer

- `datacore report` no longer says "1 preflight check needs attention" on a healthy install (it now accepts doctor's warn summary; 39b0386).
- `datacore project link` and `unlink` keep the Coordinator's copy of the project map in sync, and warn if they cannot (39b0386, 24c2791).
- An update now prints which workers it enabled or disabled, once per upgrade, with the commands to undo it (24c2791, 36243a9).
- CI test fixtures have their own git identity (39b0386).

### Bundle 0.1.89

- Workers are told exactly which evidence to record, so tasks no longer stall before review.
- Review tasks get a review-only brief.
- Dispatched workers ignore front-door logging instructions.
- Package typechecks are gated.

## Known limits

- Workers share the bridge's Runtime credential (documented).

## Upgrading

Run `datacore update`:

```sh
datacore update
```
