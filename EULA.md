# End User Licence Agreement

> **Status: placeholder — not final terms.**
>
> This file is a structural placeholder created with the installer skeleton. The actual licence
> terms for public distribution are an owner decision and have not been settled. Nothing here is
> legal text, and nothing here should be published as if it were.
>
> `services/runtime/EULA.md` and `services/runtime/LICENSE` exist in the private repository, but
> they were not written to cover redistribution to third parties.
>
> Decisions required before this file can be completed:
>
> - Who the licensor is (individual or a registered company)
> - Permitted use: evaluation only, personal use, or commercial use
> - Redistribution: permitted or prohibited
> - Warranty and liability position
> - Data handling statement — Datacore runs locally and sends nothing to the licensor, which
>   should be stated explicitly because users will ask
> - Governing law (Western Australia, presumably)
> - Whether third-party component licences need an accompanying notice file (Postgres, and the
>   bundled container base images)
>
> The installer must not be published with this placeholder in place of real terms.
